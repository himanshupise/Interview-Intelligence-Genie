# Interview Intelligence Genie: Workato Genie

An AI-powered interview evaluation solution for Workato. Once a candidate has been shortlisted by the HiBob Smart Talent Sourcer genie, recruiters use the **Interview Intelligence Genie** to prepare interviews, evaluate each interview round, record round approvals, and produce the HR Evaluation Report and the Final Evaluation Report. Guides and reports are generated by OpenAI.

- **Owner:** Harbinger Group
- **Guide version:** 1.0 (2026)
- **Audience:** Client administrators and operations teams

---

## 1. Project Overview

### Purpose

The Interview Intelligence Genie takes over after the Hibob Smart Talent Sourcer genie has pulled candidate data from HiBob and generated an AI score using its 7-dimension scoring model. For each shortlisted candidate it builds the evaluation package and an interview question guide for the panellists, turns each interview transcript into an evidence-based evaluation report, records the recruiter's approval or rejection for each round, and then produces the HR Evaluation Report and the Final Evaluation Report. A human always makes the final hiring decision. Recruiters work entirely in the genie's chat interface and never need to open the Workato recipe build view.

### Business problem it solves

Preparing interviews, writing up each round and consolidating feedback into one decision is slow and inconsistent when done by hand. This package gives recruiters structured interview guides, a consistent evaluation report for every round, an approval gate between rounds, and a traceable summary at the end of the process.

### Systems integrated

| System | Role |
| --- | --- |
| Workato | Hosts the skill recipes, functions, the Genie and the data tables |
| OpenAI | Generates the interview question guide and the evaluation reports, and its calls are logged for audit |
| Gmail | Sends candidate approval and rejection emails |
| HiBob Smart Talent Sourcer genie  | Upstream source of the role blueprint, candidate profile and match score |

### How it works

1. Hibob Smart Talent Sourcer genie pulls candidate data from HiBob and generates the AI match score. Candidate profiles are filtered on that score.
2. For a shortlisted candidate, the Interview Intelligence Genie generates the evaluation package and the interview question guide for the panellists.
3. The interview takes place. The transcript and panellist feedback are captured.
4. The Genie generates the Candidate Interview Evaluation Report from the interview transcript, panellist feedback, candidate email and job role.
5. The recruiter approves or rejects the candidate for that round. Approval is required before the next round can be generated. An approval or rejection email can be sent to the candidate.
6. Steps 2 to 5 repeat for every round defined by the recruiter or organisation. Any two rounds are mandatory before the HR round can be created.
7. The Genie generates the HR Evaluation Report, an overall summary of all previous rounds and interview feedback.
8. The Genie generates the Final Evaluation Report with all-round summaries and the overall score, from the HR transcript, candidate name and job role.
9. At any point, the candidate's round details can be fetched using the candidate's email.

## 2. Features and Workflows

### Features

- Evaluation package and interview question guide generation for each round
- Candidate Interview Evaluation Report for every interview round
- Recruiter approval or rejection per round, with an approval gate before the next round
- Any two mandatory rounds before the HR round
- HR Evaluation Report summarising all previous rounds
- Final Evaluation Report with all-round summaries and an overall score
- Candidate round details lookup by email
- PDF creation with a shareable link for reports
- Candidate approval and rejection emails through Gmail
- Audit trail of every OpenAI call
- Credentials kept in Workato Connections only, never in recipe steps
- Access to the Genie limited to chosen user groups

### Skill recipes

| Order | Asset | What it does |
| --- | --- | --- |
| 1 | `[IIG] SKILL │ 001 │ Generate Interview Guide` | Creates the evaluation package and the interview question guide for a round. |
| 2 | `[IIG] SKILL │ 002 │ Candidate Interview Evaluation report` | Generates the evaluation report for a round from the interview transcript, panellist feedback, candidate email and job role. |
| 3 | `[IIG] SKILL │ 003 │ Approve or Reject the candidate for a round` | Records the recruiter's approval or rejection for a round. |
| 4 | `[IIG] SKILL │ 004 │ HR Evaluation Report` | Summarises all previous rounds and interview feedback. |
| 5 | `[IIG] SKILL │ 005 │ Final Evaluation Report` | Produces the all-round summary and overall score from the HR transcript, candidate name and job role. |
| 6 | `[IIG] SKILL │ 006 │ Get the candidate round details` | Fetches a candidate's round details using the candidate's email. |

### Callable recipes (functions)

| Asset | What it does |
| --- | --- |
| `[IIG] FUN │ 001 │ Generate the question guide` | Generates the interview question guide for the panellists. |
| `[IIG] FUN │ 002 │ Sub function Generate the Question Guide` | Supporting sub-function used by the question guide generation. |
| `[IIG] FUN │ 003 │ Candidate Approval/Rejection Email` | Sends the approval or rejection email to the candidate through Gmail. |
| `[IIG] FUN │ 004 │ Create PDF and share link` | Converts a report to a PDF and returns a shareable link. |

### Connections

- `[IIG] CON │ 001 │ OpenAI Account` (interview guide and report generation)
- `[IIG] CON │ 002 │ Gmail Account` (candidate approval and rejection emails)
- `Slack Workspace`(chat interface)

### Data tables

- `interview`:  interview details and round information for each candidate.
- `evaluation_package`:  the evaluation package generated for each candidate.
- `openai_audit_log`:  records each OpenAI call.

### Lookup tables and environment properties

The package has no lookup tables. It has one environment property:

| Property | Value to set |
| --- | --- |
| `companyName` | The customer's organisation name (for example, Harbinger Group) |

If another customer-specific value is added later, keep it in an environment property, not inside a recipe step.

## 4. Installation and Deployment

### 4.1 Import into Workato

1. Log into the customer's Workato workspace.
2. Create a new folder named **Interview Intelligence Genie** to hold all imported assets.
3. Go to **Tools → Recipe Lifecycle Management**.
4. Select **Import Package**, choose the **Interview Intelligence Genie** folder as the destination, and upload the zip file.
5. Confirm the import completes without errors and shows these assets:

   | Asset type | Count |
   | --- | --- |
   | Skill recipes | 6 |
   | Functions | 4 |
   | Genies | 1 |
   | Data tables | 3 |
   | Connections | 2 |
   | Manifest Dependency | 3 |

### 4.2 Configure connections and properties

Recipes are imported inactive and unconfigured. Open the imported **Interview Intelligence Genie** project, set the `companyName` environment property, and re-authorize both connections with the customer's own credentials.

| Connection | What to re-authorize |
| --- | --- |
| OpenAI account | Customer's OpenAI API key |
| Gmail account | Customer's Gmail account used to send approval and rejection emails 
| Slack account | Customer's Slack workspace | 

Double-check every property and connection before moving on. A missed value here is the most common cause of failure in the next steps.

### 4.3 Register skills and grant access

1. In the Genie, confirm all six skills are registered under Enterprise skills with the correct "Use when" text and show as **Active**.
2. Confirm each skill uses the correct functions (FUN | 001 to FUN | 004) and that they are present and active.
3. Under **End user access**, add the user group that should be able to use the Genie. For testing, create a group (for example, "Test") under **Genie → End user access** and add the intended users.
4. In the Genie's **Triggers**, add the chat interface your organisation uses under "Chat with this genie in". Confirm it shows **Active**.
5. Confirm only the intended users or groups have access, not the entire "Everyone" system group, unless that is intentional.

### 4.4 Activate and verify

Activate the skill recipes and the Genie. No manual run is needed.

Test with one sample candidate, in this order. Do not move to the next test until the previous one succeeds in both the job history and the data tables.

| Order | Skill | Test | Confirm |
| --- | --- | --- | --- |
| 1 | `[IIG] SKILL 001 `| Ask for the interview guide for a sample candidate's round. | A row appears in `Evaluation_package` and the question guide is returned. |
| 2 | `[IIG] SKILL 002` | Provide a sample transcript, panellist feedback, candidate email and job role. | The report is returned and a row appears in `Interview`. |
| 3 | `[IIG] SKILL 003` | Approve the candidate for round 1. | The decision is recorded, the Gmail email is sent, and the next round cannot be generated without approval. |
| 4 | Technical rounds | Repeat tests 1 to 3 for the second technical round. | The HR round is blocked until both technical rounds are complete. |
| 5 | `[IIG] SKILL 004` | Ask for the HR Evaluation Report. | It summarises all previous rounds and feedback. |
| 6 | `[IIG] SKILL 005` | Provide the HR transcript, candidate name and job role. | The report has all-round summaries and an overall score, and the PDF share link opens. |
| 7 | `[IIG] SKILL 006` | Look up the sample candidate by email. | All round details are returned. |

After every test, confirm a matching entry appears in `Openai_audit_log`. Treat the deployment as complete only after a clean run in both the Workato job history and the chat interface.

## 6. Security, Testing and Support

### Credential handling

- Never hard-code secrets in recipe steps. Always use Connections for OpenAI API keys and Gmail accounts.
- Credentials never travel with a package. Every connection must be re-authorized in each workspace after import.
- Keep customer-specific values out of recipe steps. Use environment properties.
- Use separate credentials per environment (for example, OpenAI Dev and Prod keys, and a test Gmail account versus the production account).
- Document who owns credential rotation for OpenAI and Gmail.
- Turn on SSO if the customer requires it.

### Access control and least privilege

Each customer gets their own workspace, so recipes, connections and data stay isolated from other customers. Invite users by email into only that customer's workspace.

| Role | Give to | Allowed | Not allowed |
| --- | --- | --- | --- |
| Administrator (customer-side, limited count) | Customer IT/HR owner | Manage users, connections and recipes as permitted by governance | Other customer workspaces |
| Operator (or similar run-focused role) | Day-to-day recruitment ops | Start/stop jobs, view job history, update connection credentials | Redesigning the core skill or report logic |
| Analyst / Viewer | Auditors, HR leadership | Read job reports and evaluation data | Change credentials or recipes |
| Recruiter / Interviewer (Genie end user) | Recruiters, hiring managers, panellists | Use the Genie to generate guides and reports, approve or reject candidates, and look up round details | Access the recipe build view, connections or environment properties |

Do not add customer users to the parent Development workspace unless they are co-builders under NDA.

**Customers may safely change:**

- Connection credentials for their own systems (OpenAI, Gmail)
- The `companyName` environment property value
- Whether a skill recipe or the Genie is started or stopped
- The Genie's Enterprise skill active/inactive toggles
- The end-user group

**Customers should not change:**

- The core logic of the evaluation, HR and final report skills
- The approval gating rules (approval per round, two mandatory technical rounds before HR)
- The prompts and scoring structure used in the reports
- Anything in another customer's workspace

### Upgrading a customer

1. Announce a maintenance window if skills must be paused.
2. Pause the Genie or stop active skill recipes.
3. Export a backup package of the current customer project.
4. Import the new package version using RLC, updating skill and function logic but keeping connections and existing data table rows.
5. Map to the existing OpenAI and Gmail connections. Do not create new connections.
6. Confirm `companyName` still shows the customer value.
7. Confirm `Interview`, `Evaluation_package` and `Openai_audit_log` were not replaced or cleared. Restore from backup if needed.
8. Smoke test: generate an interview guide (SKILL 001), then retrieve the round details by email (SKILL 006).
9. Re-enable the Genie and skills, and record the deployed version and date.

### Troubleshooting

| Symptom | What to check |
| --- | --- |
| Genie does not respond in the chat interface | The chat trigger shows Active, the connection is authorized, and the user is in the End user access group. |
| Genie replies but no guide or report is produced | The skill is attached under Enterprise skills, shows Active, and the "Use when" text is correct. |
| Skill job fails | The skill's Job history for the failed step. Then check the OpenAI key and quota. |
| Approval or rejection email not sent | The Gmail connection is authorized and FUN \| 003 shows a successful run in Job history. |
| No PDF share link | FUN \| 004 Job history, and that the report was generated successfully first. |
| Next round cannot be generated | The recruiter has approved the candidate for the current round, and for the HR round that both technical rounds are complete. |
| Round details not found | The email matches the candidate's email exactly, and a row exists in `Interview`. |
| No new audit rows | The `Openai_audit_log` table was not cleared or replaced during an upgrade. Restore from backup if it was. |
| Genie missing skills after an upgrade | Re-check the skill attachment, chat trigger and end-user access, as these must be verified after every import. |
